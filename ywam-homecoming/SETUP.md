# 서강 예수전도단 홈커밍 초대장 · 준비 가이드

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 초대장. 단톡방에 이 링크를 보냅니다 |
| `responses.html` | 준비팀 전용 답장함 (비밀번호 필요) |
| `config.js` | 장소, 회비 계좌, 문의처, 응답 주소. **이 파일만 고치면 됩니다** |
| `apps-script/Code.gs` | 답장을 구글 시트에 쌓는 스크립트 |

답장은 준비팀 구글 계정의 **구글 시트**에 한 줄씩 쌓입니다. 시트를 직접 열어 봐도 되고, `responses.html`에서 인원 요약, 세대별 현황, 남긴 말까지 한눈에 볼 수 있습니다.

## 1. 구글 시트와 스크립트 만들기 (5분)

1. 준비팀 공용 구글 계정으로 [sheets.new](https://sheets.new)에 들어가 새 시트를 만들고 이름을 `홈커밍 답장`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어 있는 코드를 지우고 `apps-script/Code.gs` 내용을 통째로 붙여넣습니다.
4. 맨 위의 `const ADMIN_KEY = 'change-me-123';`에서 따옴표 안을 준비팀만 아는 비밀번호로 바꿉니다. 바꾸지 않으면 답장함이 열리지 않습니다.
5. 저장(💾)한 뒤, 위쪽 함수 선택에서 `setup`을 고르고 **실행**을 누릅니다. 권한 승인 창이 뜨면 계정을 고르고 *고급 → (안전하지 않음)으로 이동 → 허용*을 누릅니다. 시트에 `응답` 탭이 생기면 성공입니다.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형을 **웹 앱**으로 고릅니다.
3. 실행 계정은 **나**, 액세스 권한이 있는 사용자는 **모든 사용자**로 둡니다. (로그인 없이 누구나 답장을 보낼 수 있어야 하기 때문입니다. 답장 목록은 비밀번호가 있어야만 볼 수 있습니다.)
4. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 3. config.js에 붙여넣기

```js
endpoint: 'https://script.google.com/macros/s/여기에-복사한-주소/exec',
placeDetail: '엠마오관 123호',               // 정해지면 적기
account: '카카오뱅크 3333-00-0000000 홍길동', // 회비 계좌
contact: '회장 홍길동 010-0000-0000',
```

비워 둔 항목은 초대장에 나오지 않습니다.

## 4. 올리기와 확인

- 이 저장소가 GitHub Pages로 배포되고 있다면 초대장 주소는 `https://kevintheeco.github.io/urp-invitation/ywam-homecoming/` 입니다.
- 내 번호로 한 번 답장을 보내 보고, 시트에 줄이 생기는지 확인합니다.
- `responses.html`을 열고 1단계에서 정한 비밀번호를 넣습니다. 설정 전에는 `responses.html?demo`로 예시 화면을 볼 수 있습니다.

## 알아 두면 좋은 것

- **같은 전화번호로 다시 보내면** 새 줄이 생기지 않고 기존 답장이 고쳐집니다. "고민해 볼게요"로 보냈다가 나중에 "참석 가능"으로 바꿔도 한 사람은 한 줄입니다.
- 학번 `05`, 전화번호 `010`의 앞자리 0이 사라지지 않도록 시트 전체가 텍스트 형식으로 저장됩니다.
- Code.gs를 고쳤다면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 웹 앱 URL은 그대로 유지됩니다.
- 행사가 끝나면 초대장의 약속대로 시트의 개인 정보를 지워 주세요.
- 카카오톡 미리보기 사진은 `assets/og.jpg`입니다. 주소가 GitHub Pages가 아니라면 `index.html`의 `og:image` 주소도 바꿔 주세요.
